This directory preserves four retired public contract/example snapshots in the private `park-kyungchan/agent-platform` successor. These were public source libraries, not running profile applications or actual profile configuration.

The maintained implementation is `packages/operational-context/src/backend/intent-context` and `packages/operational-context/src/backend/review`. `integration.json` records the corrective R6 adoption, every distinct HEAD source variant, unchanged extraction provenance and the canonical source hashes. Historical provenance status fields remain historical observations; they do not certify current acceptance.

`custody.json` pins all advertised refs, repository IDs, full Git bundles, immutable HEAD archives and per-file hashes. Bundles preserve every commit reachable from the selected mirrors' refs; the archives include original examples, synthetic fixtures, README, licenses and both provenance records. Archived code has no maintained writer here.

Run `bun history/public-contracts/verify-custody.ts` from the repository root to verify preserved bundle refs and every archived file. To inspect historical code without creating another maintained source tree, clone a selected `.bundle` into a fresh temporary directory. The original examples can then be read against their original exports and synthetic fixtures. Fresh independent mirror restores and strict Git object checks are recorded in `custody.json`.

The exact retirement gates are in `architecture/public-contract-retirement.json`. Local history custody does not establish published successor custody, native runtime adoption, semantic acceptance or deletion completion. GitHub deletion requires the parent-owned reviewed publication/consumer closure and exact identity readback; native profiles and credential stores remain with their owners.
