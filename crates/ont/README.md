# ont

- `specs/ont/action.md` — The contract of action list, validate and apply, their values, criteria and refusal records. Commands: `action list`, `action validate`, `action apply`.
- `specs/ont/schema-language.md` — The schema language, schema install and embedding of the engine in other programs. Commands: `schema check`, `schema install`.
- `specs/ont/log.md` — Reading the action log and the history of the log format. Commands: `log`.
- `specs/ont/store.md` — The store file, its opening rules and compact. Commands: `backup`, `compact`.
- `specs/ont/read.md` — Search, linked object-set reads and count aggregation. Commands: `search`, `around`, `aggregate`, `get`, `describe`.
- `specs/ont/index.md` — Indexing the sources of the installed schemas. Commands: `index`.
- `specs/ont/mcp.md` — The MCP server of the ont command. Commands: `mcp`.
- `specs/ont/render.md` — Generated blocks in Markdown files. Commands: `render`.
- `specs/ont/cli.md` — Installing the binary and the diagnostics of command use and input. Commands: `ont --help` and every command's input diagnostics.
