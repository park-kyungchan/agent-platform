## The boundary between the store and long-term memory

What has a key, a state or an owner is an object of the Ontology store; what a query or a check can answer is stored nowhere else. A long-term memory the user deploys after v3 holds only narrative knowledge found by meaning (how a kind of problem was solved, the tradecraft of a domain), each record naming the store objects it is about, written only by a deliberate promotion from a closed finding or a closed task, never as a side effect; it holds no credential and nothing that goes stale. The legacy service is deleted whole after a verified recovery copy (D14).
