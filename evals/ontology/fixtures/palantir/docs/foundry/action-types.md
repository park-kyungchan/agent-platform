# Action types (invented fixture text)

An action type is the only way to change
objects. Each action has parameters and a
list of submission criteria, and an action
whose criteria fail is refused as a whole.

A form for an action is a matter of the
user interface and is not decided by the
schema.

From the next release, an action may name
a side effect that runs after it applies.
This is the newest statement of the page.

The end of the invented page.
