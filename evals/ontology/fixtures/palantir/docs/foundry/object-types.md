# Object types (invented fixture text)

An object type names one kind of thing the
schema holds. Each object type has a single
primary key property that never changes.

A property has one value type. A value type
is chosen when the property is made and is
not changed in place afterwards.

A link type joins two object types. It
names its cardinality on each side and is
stored apart from either object.

An interface lists properties that several
object types share, so one reader can treat
them alike.

A title property is the one shown first.
It should be short and readable by a
person who does not know the keys.

A property may be marked deprecated; the
fixture says nothing about what follows.

The end of the invented page.
