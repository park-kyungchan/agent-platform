# Public runtime guidance content

Reviewed distribution source for canonical `AGENTS.md`, runtime references and
the generic `herdr`, `lead` and `report` skill bundles. Repository source is edited through review and then installed on the host.
This README is repository documentation, not an owned host entry.

Generic Academy routing belongs to education-platform; private teaching/reporting
ownership is planned for education-dc-gang-a after verified source/consumer transfer.
Both Academy skills are excluded here; their retained education-platform copies
do not release the disabled-tool hold or authorize direct fallback. Native Herdr hooks, per-CLI pointer files,
third-party skills and Hindsight integrations are not copied or owned. Skills
assign no permanent role to a CLI and add no instruction loader.

Content describes native integrations and existing host paths; copying it does
not execute a skill, install a runtime or authorize any described operation.
Update canonical source content deliberately through review. No generated
registry or watcher synchronizes the host.

`SHA256SUMS` records every owned source file; the manifest itself is
repository evidence outside that list. Changed paths and bytes require a hash
update. Neither source acceptance nor a merged commit proves host
synchronization, native discovery or execution.
The task owner separately authorizes and verifies any host installation.

The owned files are `AGENTS.md`, the
runtime references (including `ONTOLOGY-USE.md` for operational store reads
and Lead writes) and the three generic skill bundles (the Lead's one skill is `lead`). Each reference is
self-contained and says in its first lines when it is read. Changing values
(model names, efforts, versions, token windows, counts, dates of approvals) stay
out of `AGENTS.md` and skill frontmatter; they belong in task STATE.
