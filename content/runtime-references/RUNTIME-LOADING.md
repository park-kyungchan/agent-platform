## Hindsight: separate loading from retention and page refresh

All four confirmed runtimes register the same official coding-agents MCP implementation, with their own harness ID. Codex/Claude have official SessionStart, UserPromptSubmit and Stop hook registrations; Antigravity uses PreInvocation and Stop in its native namespace; Muse has MCP tools with no configured lifecycle injection hook. Hook entrypoint files all exist. Hooks and MCP are different clients with different config lifetimes; registration alone does not prove an event actually ran or a non-managed hook was trusted. Host registration does not guarantee that a worker exposes those tools: the Whole-Lens worker had no Hindsight tool namespace. Report that session limitation without inventing a replacement client.

The historical 2026-11-02 config readback was autoInject:pages, injectTimeoutMs5000, reflectToolTimeoutMs660000, reflectBudget:mid, gitIngest:none and retainSessions:false; it is not a new effective-config read. Global settings, per-path/harness overrides and bank routing must be distinguished. Initial page injection, per-turn roster/tool guidance, extraction, consolidation and derived-page refresh are distinct operations. In particular, **retainSessions:false does not automatically retain sessions**; do not project that dated global value onto every task override. Do not assume a Stop hook writes the full transcript or that Muse runs another CLI's hook. Use explicit selected-document retention when authorized.

This controls the periodic page/tool guidance cadence, not per-turn instruction-file rereading, session retention or derived-page refresh. Zero is not an off switch (`raw.pageRefreshEveryTurns || 1`, still present in installed coding-agents 0.8.5 on 2026-11-06).
