# A standalone HTML explanation

Read only when the user asks for a standalone HTML or scroll-driven explanation; an ordinary message never gets one. The page keeps every rule of the skill `report`: Korean prose, every term in its original English form, a concrete definition at a term's first use, no metaphor and no analogy.

- One local `.html` file of semantic prose with embedded CSS and JavaScript. Its text, diagrams and navigation work offline and without JavaScript; it loads no remote asset unless the user asks for one.
- The page scrolls normally. A diagram beside the text may highlight the current input, executor, operation or result as its explanation enters view.
- Keyboard navigation with a visible focus, readable contrast, selectable text and a complete print view. No state is shown by colour alone. It respects `prefers-reduced-motion` and reads on a phone without horizontal overflow of the whole page.
- Parallelism, retries and failures are shown only where the real system has them. Illustrated execution is labelled apart from verified behaviour; evidence and examples are labelled as such.
- When a browser is available, check these behaviours and the page without JavaScript, and report only the checks actually performed.
- The file authorizes no deployment, no illustrated command and no change of runtime configuration.
