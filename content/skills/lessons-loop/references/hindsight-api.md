# Engineering publication route

The operational home is `agent-platform` `memory/README.md`; use its Git-original,
fixed-bank publisher, private inherited FD, maintenance/recovery and readback
contracts. No agent-side direct retain/PATCH, MCP ingestion/initiative or page
refresh is an engineering write route, even when an older template names one.
A no-write task leaves only its allowed local handoff. An available API grants no
permission and a receipt does not establish completion or semantic correctness.

Publication takes reviewed-main originals, pins exact projected bytes/full derived
tags, and leaves consumers unavailable until qualified evaluation/readback passes.
Reconcile uncertain effects at the target; never resend on elapsed time alone.
The private Academy archive keeps its separate owner and `education-platform`
`content/skills/academy-student-context/references/lesson-archive.md` contract.
Preserve genuine historical/plugin attribution; do not forge it or copy private
bodies into engineering. No credential value belongs in source, argv or logs.
