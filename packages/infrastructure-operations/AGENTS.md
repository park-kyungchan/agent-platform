# Infrastructure domain library

Canonical code scope is exactly six src/domain modules: index, types, schemas, registry, validation and evaluate. Native SSH, lifecycle, updates, Desktop/backend coordination, profiles, observation acquisition, native state and evidence remain with vps-operations. Pure validation/evaluation cannot grant permission or actual acceptance. Keep immutable Ontology0.2.0; old-owner compatibility imports route to this single source. No native runtime, scheduler, store or operational dispatch is added.
