# ontology-foundation common source provider

Canonical implementation, schema and generated declaration sources for this admitted source slice live here. Semantic owner remains ontology-foundation; immutable published/local tarball versions retain their original owners and bytes. Generate only from these canonical schemas using bun run generate; do not edit generated types manually. Run bun run check. Native operational CLI, release/import/pilot/registration/verification workflows and their output/data/credential roots remain in /home/palantirkc/code/shared/ontology-foundation. This package exposes no native workflow scripts. Existing installed immutable Ontology consumers keep their own pinned tarballs. Do not repack old versions, create another native runtime, change global profiles or operate production data as a migration side effect.
