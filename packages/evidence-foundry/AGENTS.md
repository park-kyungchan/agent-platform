# evidence-foundry common source provider

Canonical implementation, schema and generated declaration sources for this admitted source slice live here. Semantic owner remains evidence-foundry; immutable published/local tarball versions retain their original owners and bytes. Generate only from these canonical schemas using bun run generate; do not edit generated types manually. Run bun run check. Native operational CLI, release/import/pilot/registration/verification workflows and their output/data/credential roots remain in /home/palantirkc/code/shared/evidence-foundry. This package exposes no native workflow scripts. Existing installed immutable Ontology consumers keep their own pinned tarballs. Do not repack old versions, create another native runtime, change global profiles or operate production data as a migration side effect.

Core Foundry construction/open requires an explicit per-instance semantic-owner policy. It imports no original checkout or copied authoritative project manifest. Native evidence-foundry service/index adapters bind their own project.json policy and preserve existing default/explicit data roots. Synthetic tests bind a test-only policy fixture; it does not grant policy authority. A standalone consumer must select its own real semantic owner policy before opening a store.
