This successor retains the exact 66 P cases from Root `41ba5aabfe043344ed19697c5231dfe38926816c` and adds 89 fixed scenarios, for 155 required cases per required subject. All expected values, pointer comparisons, equality relations and finite shape checks are in the immutable host catalogue. Every required case is compared outside the candidate process. Missing exports, fixture setup errors, extra stdout, early exit, unsupported results, nonzero exit, timeout and OOM cannot stand for a passed case.

`scenario-adapters.ts` selects only the compiled fixture families and passes the fixed candidate root to them. It accepts a scenario ID, not a command, callback, filesystem root, credential or runtime configuration. Each adapter performs a bounded sequence of actual API calls and returns values, thrown errors or observable Git/file/store state. It contains no expected verdict or completed-test count. The existing probe worker and host supervisor remain the only execution/report boundary; no runtime, scheduler, store service or test platform is introduced.
